転落牌 プライバシーポリシー

制定日：2026年9月27日　／　改定日：2026年10月8日　／　提供者：maosun-dev

1. このポリシーについて

このページは、maosun-dev（以下「開発者」）が提供するゲーム「転落牌」（iPhoneアプリ版とWeb版）で、利用者の情報をどのように扱うかを説明するものです。

2. 開発者が集める情報

開発者は、利用者の氏名・メールアドレス・位置情報などの個人情報を集めていません。

点数のランキング、役コレクション、音のオン／オフなどの記録は、利用者の端末の中にだけ保存され、開発者に送られることはありません（Game Center の世界ランキングについては 4. をご覧ください）。アプリを削除する（Web版ではブラウザのサイトデータを消す）と、これらの記録も消えます。

3. 広告について（iPhoneアプリ版）

iPhoneアプリ版では、Google LLC が提供する広告配信サービス「Google AdMob」を使って広告を表示します。広告の表示のために、次の情報が Google に送られることがあります。

  • 広告識別子（IDFA）…利用者が「トラッキングを許可」した場合のみ
  • IPアドレス、端末の機種やOSのバージョンなどの情報
  • 広告を表示した・タップしたといった利用状況
  • IPアドレスから推定されるおおまかな地域

これらは、広告の配信、広告の効果の測定、不正の防止のために Google が使います。トラッキングを許可しない場合、広告識別子は送られず、利用者の興味にもとづかない広告が表示されます。許可するかどうかは、iPhoneの「設定」→「プライバシーとセキュリティ」→「トラッキング」からいつでも変えられます。

Google による情報の扱いについては、次のページをご覧ください。

  • Google のサービスを使用するサイトやアプリから収集した情報の Google による使用
  • Google プライバシーポリシー

Web版には広告はありません。

4. 世界ランキング（Game Center・iPhoneアプリ版）

iPhoneアプリ版では、Apple Inc. が提供する「Game Center」で世界ランキングを表示します。Game Center にサインインしている場合、ゲームの点数が Game Center のニックネームとともに Apple に送られ、ほかのプレイヤーのランキングに表示されます。開発者がニックネームなどの情報を受け取ることはありません。Game Center を使いたくない場合は、iPhone の「設定」→「Game Center」からサインアウトできます。Apple による情報の扱いは Apple のプライバシーポリシーをご覧ください。

5. GitHub Pages の利用について

Web版は GitHub, Inc. が提供する GitHub Pages で配信しています。また、iPhoneアプリ版は起動したときに、広告の表示回数の設定ファイルを GitHub Pages から読み込みます。これらのとき、安全のために GitHub が IPアドレスなどのアクセス記録を保存することがあります。詳しくは GitHub のプライバシーに関する声明をご覧ください。

6. 子どもの利用について

このゲームは13歳未満の子どもを対象としていません。開発者は、13歳未満の子どもの個人情報を意図して集めることはありません。

7. このポリシーの変更

内容を変えるときは、このページで知らせます。大きな変更があるときは、アプリのアップデートの説明でもお知らせします。
